Primeiro:
Abrir um terminal na pasta raiz do projeto "BACK-VOLUNTARIADO-EXTENSAO"

Para instalar as dependências que o Python precisa, vamos rodar um comando de cada vez:
```shell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Inicializar no Alembic:
```shell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Iniciar Alembic
```shell
.\.venv\Scripts\python.exe -m alembic init alembic
```

Depois de 'config = context.config' abra uma nova linha e importe o seguinte:
```python
from app.core.config import get_configurations
from app.db.base import Base
import app.models
```
Após isso, antes de "target.metadata" você vai configurar o seguinte:

```python
configurations = get_configurations()

config.set_main_option(
    "sqlalchemy.url",
    configurations.url_database.replace("%", "%%"),
)
```

Na linha: target_metadata = None substitua o 'None' por 'Base.metadata' ficando dessa forma:
```python
configurations = get_configurations()

config.set_main_option(
    "sqlalchemy.url",
    configurations.url_database.replace("%", "%%"),
)

target_metadata = Base.metadata
```

Mais para baixo no arquivo, encontre a função run_migrations_online(). Dentro dela, você terá uma linha dessa forma:
```python
with connectable.connect() as connection:
        context.configure(
            connection=connection, target_metadata=target_metadata
        )
```

Substitua para ficar dessa forma:

```python
with connectable.connect() as connection:
        context.configure(
            connection=connection,
            target_metadata=target_metadata,
            compare_type=True,
            render_as_batch=True,
        )
```

Agora pode fazer a migração inicial:
.\.venv\Scripts\python.exe -m alembic revision --autogenerate -m "create initial tables"

Execute a migração:
.\.venv\Scripts\python.exe -m alembic upgrade head

E inicie a API:
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
